# Minecraft Modpacks
Custom modpacks I created for playing with friends.

- `base/` per version markdown files, listing base essential and QoL mods. No gameplay, decor or similar mods.
- `packs/` per version markdown files, listing gameplay, decor and similar mods. No base essentials. The files are sorted in the schema `<game_version>-<year>-<month>.md` where `year` and `month` referencing mainly when the pack was first created.
